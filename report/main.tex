\section{Updated security proof}
We then consider an updated security proof, modeled over the framework in~\cite{C:ABDPW25}. 
In~\cite{C:ABDPW25} the proof strategy is:
\begin{enumerate}
    \item Use Lemma 2.2 to pass from EUF-CMA to identification protocol, loss $\numRO $, multiplicative
    \item Swap the actual commitment distribution for the stationary distribution, with additive loss in $\numOSign$.
    \item Swap the hint distributions
\end{enumerate}

Here we propose to swap the reduction order.
\begin{enumerate}
    \item Swap the actual commitment distribution for the stationary distribution, with additive loss in $\numOSign$.
    \item Use Lemma 2.2 to pass from EUF-CMA to identification protocol, loss $\numRO $, multiplicative
    \item Swap the hint distributions
\end{enumerate}
In this way we do not have anymore to combine the multiplicative loss in \numRO by the additive one in \numOSign.
This swap, however, does not come for free. 
We have to be careful with swapping the commitment distribution properly, essentially we need to rewrite the proof of Lemma 2.2 (\cite[Lemma~3.5]{EC:AABN02}) to use the hints immediately when simulating the signatures. 
This will avoid to ``bake'' the multiplicative loss inside the reduction. This can be seen as a refinement of the hint-framework.
Essentially we need to avoid using Lemma 3.1~\cite{C:ABDPW25} and instead add a game hop in the lemma proof in which we directly swap in the \textbf{Initialize} step. 
The important step is that this should happen \emph{after} the game hop in which the $\mathsf{bad}$ flag is handled, i.e. between the first and second game.
Roughly the games should be as follows:
\begin{games}
    \game{hintIMPPA} The game for hint-IMP-PA, like Definition 3.5~\cite{C:ABDPW25}. Here the same design idea as in \cite[EC:AABN02] should be used to define the sign and oracle game. The signatures just return hints.
    \game{Gsim} The game for hint-IMP-PA, but with the simulator using the hints to simulate the transcripts. This 
    \game{G0} Possibly multiple games that do the same as in games G0,G1,G2 of \cite{EC:AABN02}
    \game{hvzk} this game hop swap the simulated transcripts with the real ones, using the hints. This should reduce to the hint-hvzk game, or a similar property.
    \game{minent} Possibly multiple games that do the same as in games G3,G4 of \cite{EC:AABN02} to account for the min-entropy of the commitment distribution.
    \game{EUFCMA} The final game, which is the EUF-CMA game.
\end{games}


We also plan to use \cite[Proposition 1]{cryptoeprint:2026/1775} to bound the distance.


Contents of the section:
\begin{enumerate}
    \item Explicit simulator definition
    \item Explicit reduction as in the spec, assuming negligible failure
    \item Reduction for the case in which there are non-negligible failures
\end{enumerate}
