% cryptocode (as shipped with TeX Live 2026) makes \label safe to use
% inside a \procedure box by binding \@pc@original@label to \ltx@label at
% \begin{document} -- but \ltx@label is only ever defined by hyperref's
% nameref.sty. This HTML-build wrapper does not load hyperref (it is a
% small per-game SVG, not a full document), so that binding silently fails
% and \label prints its argument as plain visible text instead of being
% invisible. Providing the fallback here, before \begin{document}, is
% enough: cryptocode's own \AtBeginDocument hook then finds a real
% \ltx@label to alias. (Inert -- and harmless -- on cryptocode versions
% that predate this mechanism, since nothing else references \ltx@label.)
\makeatletter
\let\ltx@label\label
\makeatother
