% Automatic line numbering and cross-references.
%
% Numbering itself is cryptocode's own (each \procedure below is given the
% `linenumbering` key); what needs setting up here is only the *reference*
% side.  cryptocode's line-number column is produced by \pcln, which does
% \refstepcounter{pclinenumber} before typesetting the number -- so a
% \label placed as the first token of a pseudocode line's content lands
% right after that \refstepcounter and captures the number just assigned
% to that line.  \gline{name} is that label call; a citation elsewhere in
% the paper then just writes \ref{name} and is correct by construction,
% even if lines are later added, removed or reordered.
%
% (cryptocode already makes this safe to do inside a \procedure box: it
% locally redefines \label so that it is a no-op during the box's internal
% width-measuring pass and only fires for real once, on the pass that
% actually draws the box.)
%
% \gline is a \providecommand guarded by \ifgamelabels so that a
% consumer which renders the same tagged source more than once in one
% document (e.g. gameops/standalone.tex, which shows both per-game diffs
% and a consolidated figure) can set \gamelabelsfalse to avoid re-defining
% the same labels several times over. The paper itself renders the source
% exactly once (a single consolidated \tfrenderfigure), so it leaves
% \ifgamelabels at its default of true.
\newif\ifgamelabels
\gamelabelstrue
\providecommand{\gline}[1]{\ifgamelabels\label{#1}\fi}
