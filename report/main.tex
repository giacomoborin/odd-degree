\section{Lattice analysis}
We need to analyze the properties of the lattice $\Hom(\Ecom, \Echall)$, deducing the existence of a suitable response isogeny $\phi_\resp$ of odd degree from the lattice minima.

We explain now how to use the natural surjection $\Hom(\Ecom, \Echall) \to (\mathbb{Z}/2\mathbb{Z})^2$ for this goal.


We also need to compute the intersection between the boundary of the ball of radius $D$ and the shifted foundamental domain of the lattice $\Hom(\Ecom, \Echall)$.

\section{Impact on SQIsign}
Note for comparison: the correct value for log of challenge degree in the even case is $\log p / 2 + \lambda$.
This because we need, by the soundness argument of SQIsign2D-west to have $e_{resp} + e_{ch} \leq e$, with $e$ the logarithm of the challenge degree.
For odd case is, given a failure $\leq 1/\epsilon$ the num of $(2,2)$ isogenies is $\log p / 2 + \log \epsilon / 4$.
For the case of:
